## 3. Что было не так с отслеживанием

**Clarity.** Ни одного собственного события — только угаданные «умные события».

**GTM `GTM-N8KCJMXP`** (GA4 `G-J0FFZFF60K`, Google Ads `AW-17838270814`):

| Что | Как настроено | Проблема |
|---|---|---|
| Конверсия Ads: звонок | клик по `tel:` | ок |
| Конверсия Ads: заказ | видимость элемента на `/thanks` | ок |
| Конверсия Ads: консультация | отправка формы с текстом **«Отримати консультацію Відправити»** | модалки «Швидке замовлення», «Термінове замовлення», «Порахувати обсяг», «Оренда апарата», «Отримати оптовий прайс» (часть) и форма контактов не совпадают по тексту — не считаются |
| Конверсия Ads: опт | форма с текстом «Отримати оптовий прайс» | ломается при любой смене надписи |
| GA4 add_to_cart | событие `order_button_click` | уходит только из модалки на главной; каталог и карточки товара не отправляют |
| **Мессенджеры** | **нет** | Telegram / WhatsApp / Viber — главный канал заявок — не отслеживается ни в GA4, ни в Ads |
| 5 тегов | на паузе | — |

Итог: Google Ads оптимизирует кампании по редким и неполным сигналам. Это одна из причин, почему реклама приводит трафик, который не конвертирует.

## 5. Что сделано в коде 18.09 (`src/utils/analytics.js`)

Все события уходят **одновременно** в Clarity (`clarity("event")`, теги сессии) и в `dataLayer` для GTM. Персональные данные не передаются.

| Событие | Когда | Параметры (dataLayer) | Теги сессии Clarity |
|---|---|---|---|
| `add_to_cart` | любое добавление в корзину (каталог, модалка главной, допродажа боксов) | `value`, `currency`, `item_name`, `item_variant` | `cart_item` |
| `lead_form_open` | открыта любая модалка заявки | `lead_form` (заголовок модалки) | `lead_form_opened` |
| `generate_lead` | отправлена заявка: любая модалка, форма контактов, заказ из корзины | `lead_type` (`request` / `contacts` / `order`), `lead_form`, `value` | `lead_type`, `lead_form`; запись сессии помечается |
| `contact_click` | клик по телефону, Telegram, WhatsApp, Viber, Instagram, почте — в любом месте сайта | `contact_channel`, `page_type` | `contact_channel`; запись помечается |
| `view_cart` | открыта `/basket` | — | — |
| `begin_checkout` | открыта `/delivery` | — | — |
| `purchase` | отправлен заказ из корзины | `value`, `currency` | — |

Теги на каждой сессии: `page_type` (home / catalog / category / product / geo / niche / niche_hub / blog / wholesale / contacts / cart / checkout / thanks / faq / info), **`entry_page_type`** и `entry_path` (страница входа), `lang`.

**Как смотреть в Clarity:** Filters → Custom events / Custom tags. Например, конверсия гео-страниц: `entry_page_type = geo` + событие `generate_lead` или `contact_click`, отдельно по каналу (Traffic → Channel).

**Воронка в Clarity** (Settings → Funnels → New funnel → Smart events / Page visits): `add_to_cart` → `begin_checkout` → `purchase`; вторая — `lead_form_open` → `generate_lead`. Собрать после того, как события накопятся (1–2 дня).

## 6. Что сделать в GTM (нужен доступ к `GTM-N8KCJMXP`)

В аккаунте Google, с которого работали 18.09, этого контейнера нет — есть непринятое приглашение. Нужно, чтобы владелец контейнера дал доступ или сделал шаги сам:

1. **Триггеры «Специальное событие»**: `generate_lead`, `contact_click`, `purchase`, `add_to_cart`, `begin_checkout`.
2. **GA4 (G-J0FFZFF60K)**: теги «Событие GA4» с теми же названиями и параметрами из dataLayer (`lead_type`, `lead_form`, `contact_channel`, `value`, `currency`). В GA4 отметить `generate_lead` и `purchase` как ключевые события.
3. **Google Ads**:
   - конверсия «Заявка» — на `generate_lead` и на `contact_click` с `contact_channel` = telegram / whatsapp / viber / phone;
   - конверсия «Заказ» — на `purchase` со значением `value`.
4. **Снять старые триггеры по тексту формы** («Відправити», «Отримати консультацію Відправити», «Отримати оптовий прайс») и `tel:`-клик, иначе конверсии задвоятся с новыми.
5. Проверить в режиме предварительного просмотра GTM: модалка «Швидке замовлення», форма контактов, заказ из корзины, клик по Telegram.
