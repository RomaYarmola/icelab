### 3.3 Каннибализация

**(1) ВЧ «сухий лід / сухий лід купити» — четыре URL на один интент**

| URL | «сухий лід» | «сухий лід купити» |
|---|---|---|
| `www.icelab.com.ua/` (старый адрес) | **516 / поз. 8,2** | — |
| `/` | 141 / поз. 19,9 | 79 / поз. 9,0 |
| `/suhyi-lid-kyiv` | 63 / поз. 48,4 | 73 / поз. 12,3 |
| `/suhyi-lid-kharkiv` | 57 / поз. 65,4 | 11 / поз. 47,4 |
| `/catalog/c/suhyi-lid` — **должна отвечать** | **не в индексе** | **не в индексе** |

Google не находит страницу, созданную под этот интент, и перебирает всё подряд. Лечится индексацией категории, а не правками текстов городов.

**(2) Криобластинг: статья обыгрывает категорию по коммерческим запросам**

| Запрос | Статья «як обрати апарат» (ru) | Категория «чистка сухим льдом» (ru) |
|---|---|---|
| аппарат для чистки сухим льдом цена | **49 / поз. 9,0** | 58 / поз. 22,8 |
| аппарат для чистки сухим льдом | **48 / поз. 10,8** | 50 / поз. 29,4 |
| установка для чистки сухим льдом | **33 / поз. 13,1** | 61 / поз. 28,0 |

Причина видна в краулере: у категории **нет ни одного содержательного H2** — только «Часто беруть разом» и служебные блоки, 599 слов. У статьи 837 слов и разделы «Скільки коштує», «За якими параметрами обирають». Google отдаёт коммерческий запрос странице, где есть ответ про цену. Выдача по «аппарат для чистки сухим льдом цена» — это каталоги (Prom, Machineryline, Energomash): **нужна категория с ценой и сравнением, а не статья**.

**(3) Русские города ловят национальные запросы** — `/ru/suhyi-lid-kyiv` получает «сухой лед купить» (61 / поз. 6,5), потому что `/ru/catalog/c/suhyi-lid` почти не видна (2 показа). То же следствие проблемы (1).

**(4) «Харчовий лід» и «Сухий лід» показывают одни и те же SKU.** Известное решение (интент-страница под HoReCa). Сейчас показов почти нет, но при росте — следить, чтобы тексты не сходились.

### 3.4 Прочее техническое

- **www-дубль**: редирект 308 работает, но 1 030 показов всё ещё на www. Проверить, что все внешние ссылки (co2lab.pro — 73 ссылки, профили Google Карт, Instagram) ведут без www.

- **Хаб блога без ссылок из тела**: статьи — единственные страницы сайта без контекстного входа.

## 5. Усиление приоритетных страниц

**Вопросы закрыть**: скільки коштує, де купити, яку гранулу, скільки брати, скільки зберігається, чи безпечно поруч з їжею.

### 5.2 Категория «Чистка сухим льодом» — `/catalog/c/chystka-suhym-lodom`

**Реальный интент**: коммерческий B2B — сравнить оборудование, понять цену и окупаемость. Выдача — каталоги оборудования.
**Новая структура:**
1. H1 «Апарат для чистки сухим льодом (кріобластинг)» + цена от, срок поставки, гарантия — в первом экране;
2. карточка WC60 Pro с ТТХ-таблицей: расход льда кг/ч, давление, требуемый компрессор (м³/мин), вес, длина шланга;

4. «Скільки коштує година роботи» — перенести/продублировать расчёт из статьи (лёд кг/ч × цена + воздух);
5. «Кріобластинг vs піскоструй / содоструй / мийка» — таблица;
6. отрасли → нишевые страницы группы «Промисловість»;
7. FAQ (FAQPage): чи пошкоджує поверхню, чи потрібен захист, скільки льоду на зміну, чи є демо;

**Статью** «як обрати апарат» оставить информационной: снять из Title «скільки коштує», поставить в начале ссылку «Ціна і характеристики апарата — у каталозі».

3. **Каждый товар** → категория (крошки), ниши «Для яких задач беруть» (автоматически с 15.09), схожие и «з цим купують».
4. **Категория** → свои ниши, 2 опорные статьи, города, опт (для крупных фасовок).

7. **Анкоры** на денежные страницы разнообразить по реальным запросам: «купити сухий лід», «сухий лід ціна», «сухий лід оптом», «апарат для чистки сухим льодом», «термобокс для сухого льоду».

### 8.3 Система: как запускать нишевую страницу за 30 минут

**Устройство** (код — `src/lib/nicheEngine.js`, `src/lib/niches.js`, шаблон `NicheLanding.jsx`):

1. **Одна ниша = один объект данных** на двух языках: `slug`, `group`, `status`, правила товаров и тексты по схеме (lead, факты, набор, шаги, таблица «скільки брати», безопасность, FAQ, CTA).
2. **Товары прикрепляются правилами, а не списком адресов**: `{ category: "dry-ice", granule: "16", weights: [5, 10] }`, `{ category: "ice-box" }` или `{ slug: "aparat-…" }`. Новая фасовка в Sanity появляется на всех подходящих нишах сама; удалённый товар не ломает страницу.
3. **Статус `draft`** — страница собирается и открывается по прямому адресу, но `noindex`, не попадает в sitemap, хаб и перелинковку. Можно вычитать на проде.
4. **Статус `live`** — автоматически: страница uk+ru, sitemap с hreflang, карточка в хабе в своей группе, блок «Для яких задач беруть» на всех подходящих товарах, «Схожі задачі» на соседних нишах, `llms.txt`, ItemList + FAQPage + BreadcrumbList.

**Процесс запуска новой ниши:**

| Шаг | Кто | Время |
|---|---|---|
| 1. Проверить спрос: автоподсказки Google UA (uk+ru), выдача, есть ли профильные страницы у конкурентов | SEO | 10 мин |
| 2. Выбрать группу и правила товаров; проверить, что ниша не дублирует категорию | SEO | 5 мин |
| 3. Заполнить тексты по схеме. **Только проверяемые цифры**: статьи и FAQ IceLab или открытые рекомендации с указанием источника в комментарии | копирайтер | 60–90 мин на язык |
| 4. `status: "draft"`, деплой, вычитка на проде | SEO + клиент | 10 мин |
| 5. `status: "live"`, деплой, запрос индексации uk-URL в GSC | SEO | 5 мин |
| 6. Через 3–4 недели: запросы страницы в GSC → дописать FAQ под реальные формулировки | SEO | 20 мин |

**Правила контента, зашитые в шаблон:**
- lead — самостоятельный ответ на 40–60 слов с цифрой, гранулой и условием получения;
- блок безопасности обязателен для бытовых и событийных ниш;
- если IceLab чего-то не продаёт (цветные дымовые шашки, услуга очистки) — прямо писать об этом;
- ниша не должна отвечать на интент категории: «апарат для чистки» — это категория, «гранула для кріобластингу» — ниша.

### 8.4 Решения за клиентом

1. **Услуга кріобластингу.** Есть спрос «криобластинг цена за м2», «чистка двигуна сухим льодом». Если IceLab делает очистку или готов давать контакты студий-партнёров — отдельная страница с самым высоким повтором. Если нет — страница только для студий-покупателей апарата.
2. **Малый набор для гендер-паті** — 5 кг льда + компактный бокс. Сейчас минимальный бокс 15 кг избыточен для самой массовой B2C-ниши; конкуренты продают наборы за 820 грн.
3. **Замер тумана** — время на 5/10/15 кг в генераторе, чтобы убрать расхождение между FAQ, статьёй и прокатчиками.
4. **Мешок для льда** — заводить ли товар (15 показов на 49-й позиции).
5. **Фото складов** — для «як доїхати» и разметки LocalBusiness (удалённое 11.09 фото было чужим).
